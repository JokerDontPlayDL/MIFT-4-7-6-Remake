# MIFT-4-7-6-Remake

### 模板概述

  本模板是由<a href="https://space.bilibili.com/3493128206027407">@不玩DL的小丑</a>主持修改<a href="https://chinadlrs.com/app/41">冰焰模板4.7.6</a>而成。
  特别鸣谢<a href="https://space.bilibili.com/3546927027194565">@RV凛川</a>帮忙编写制作皇冠代码。

### 使用须知(重要)
<p>
  
  1.使用引擎：Unity2022.3.62f2c1  **<span style="background:#ffeb3b">请使用此Unity版本或更高的Unity版本来打开这个模板</span>**
  <br>2.如何下载模板？
  <br>如果您有Github账号：点击页面右上角的“Use this template”，新建一个你自己的仓库。
  <br>如果您没有Github账号：在显示仓库目录的上方有一个“Code”，点击并选择“Download ZIP”，就可以将模板下载到本地
</p>

### 我们增加的功能
